# 怎么放任务

**一个任务 = 一个文件夹。** 文件夹里放这条任务自己的提示词和图片。

```
queue/
  001-椰子水/
    prompt.txt          ← 这条的提示词
    1.jpg               ← 这条的参考图
    2.jpg
  002-手机壳/
    prompt.txt
    主图.png
  003-咖啡机/
    prompt.txt
    a.jpg  b.jpg  c.jpg
```

## 规则

- **顺序**：按文件夹名排序依次生成，所以用 `001-` `002-` 这样编号最省心。
- **提示词**：文件名必须是 `prompt.txt`（也认 `提示词.txt`、`prompt.md`），UTF-8 编码。
  - 不用自己写前缀，工具会自动在开头加上 `config.json` 里配的那句话。
- **图片**：文件夹里所有 `.jpg .jpeg .png .webp .apng` 都算，按文件名排序，最多 30 张。
- **跑完去哪了**：成功的整个文件夹移到 `queue-done/`，结果不确定的移到 `queue-failed/`。
  所以 `queue/` 里剩下的永远是「还没做的」，不会重复生成。
- **额度不够怎么办**：跑不完的留在 `queue/`，明天额度恢复后再点一次 `开始批量.bat` 就接着跑。

## 以 `_` 或 `.` 开头的文件夹会被忽略

比如这个说明文件所在的位置，还有你自己的草稿文件夹，命名成 `_草稿` 就不会被执行。
